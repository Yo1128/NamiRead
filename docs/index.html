潮汐手记

潮汐手记 试读

抵岸

车门打开的一刻，海风先挤进了车厢。车站离水还有两条街，我却已经听见了碎石在浪底滚动的声音。

寄存处的人给了我一把小钥匙。那是我在这座陌生小城里拥有的第一件东西。

堤上的风

老堤从街尾起步，拐过水塔，笔直地伸进灰色海面。沿途没有椅子，只有几块朝向不同的石头。

有人用白漆在石头上写了年份。雨水抹去了一半数字，剩下的几笔，恰好像一小群掠过水面的鸟。

潮线

退潮以后，海在沙上留了一条细线。它绕过礁石，在一截漂木前分开，又在更远处合拢。我沿着它走，像沿着一封还没有读完的信。

早晨的堤岸很静。远处有人把一只旧木船翻过来，敲掉船底的藤壶。

翻页与排版
左右滑动翻页，按喜好调整字号、行距和页边距。横置平板可以并排读两页。
书源与离线
导入书源后可搜索作品、浏览目录。下载支持暂停和续传，整书可另存为 TXT。
书签与备份
阅读进度自动保存在设备上。更换设备时，可通过备份带走藏书、书签和阅读位置。

用 NamiHub 读电脑上的书

NamiRead 0.7.0 支持直接阅读电脑共享的 TXT 和 EPUB，也可下载整本离线阅读。

使用 0.7.0 时，在 Windows 上用 NamiHub 共享存书的文件夹。手机连到同一局域网后，在书架点「＋ → 浏览 NamiHub 书库」，输入八位配对码。点书名在线阅读，也可以在书名旁的菜单中选择「下载到本机」。
